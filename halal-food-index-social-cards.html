Social preview cards

One template per page type, filled from the database at build time. All six are 1200×630 — the size WhatsApp, iMessage, X, Facebook and LinkedIn all read. Scroll to the bottom to see them in a chat, which is where they'll actually be seen.

In the place it matters

Same link, same message. The only difference is whether the tags exist.

How this actually works

These are HTML, not hand-drawn images. Next.js can render them to PNG on demand at /api/og — the URL carries the page's data, so /api/og?type=chain&name=Nando's&status=partial returns that card. 487 venues means 487 unique preview images and no design work per venue.

Two tags per page do the job: og:image pointing at that URL, and twitter:card set to summary_large_image so X and iMessage use the wide format rather than a thumbnail.

The one rule worth holding: the verdict or the venue name has to be readable at thumbnail size. WhatsApp renders these around 250px wide on a phone. Anything under about 4cqw disappears — which is why the chain card puts the answer at 8.6cqw and almost nothing else on it.
